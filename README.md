🎓 Student Management System

A simple CRUD (Create, Read, Update, Delete) based web application built using PHP & MySQL to manage student records.



🚀 Features

➕ Add new student

📋 View all students

✏️ Update student details

❌ Delete student record

🎨 Simple and responsive UI using Bootstrap



🛠️ Technologies Used

Frontend: HTML, CSS, Bootstrap

Backend: PHP

Database: MySQL


📂 Project Structure

index.php → Add Student

display.php → Show all students

update.php → Update student details

delete.php → Delete student

config.php → Database connection




📌 Future Improvements

🔐 Add authentication (login/signup)
